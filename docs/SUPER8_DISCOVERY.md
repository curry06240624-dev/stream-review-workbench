# Super 8 Environment
- 產品：InsightArk v6.16.3（console.no8.io），SUPER 8 Studio／雲發互動科技
- 組織：浦森汽車。另有一個 Curry 自開的乾淨試用組織「Smart」（所有渠道未連接）
- Curry 的角色 `customer-readonly` 看得到：數據總覽／訊息中心／應用市集／渠道設置／AI 點數儲值中心
- 看不到（Smart 試用帳號有、浦森沒開給這個角色）：獵客派遣／聊天機器人／自動旅程／客戶中心／群發訊息／客製化問卷
- 角色種類（從成員績效表）：`admin`／`private-only`／`customer-readonly`

# Major Modules
- **數據總覽**：組織總覽及分析（客戶數、訊息量、各渠道）／標籤量統計（曲線＋查標籤名）／
  **客服數據**（已指派、未指派、案件分析；成員績效表；平均等待/處理時數；進件熱圖）
- **訊息中心**：1 對 1 聊天室／群組對話；搜尋顧客名稱；篩選＝平台、收件匣、顧客標籤（包含/不包含）；
  收件匣種類＝所有／未指派／完成／所有已指派／被指派／聊天機器人／垃圾匣／無效會員
- **對話畫面**：指派、標記完成、智能回覆（AI 建議）、智能摘要、記事本（上限 30 則）、
  「LL 正在輸入訊息…」、「其他專員正在回覆中…」、客戶資訊／官網資訊分頁
- 每頁都有「匯出目前數據」（尚未實際按過——會下載檔案，要 Curry 自己按一次看欄位）

# Customer Structure
- 顯示名稱是 LINE 暱稱，**公司在裡面手動塞資料**：`M/D` 日期前綴、`B@` 前綴、`-已購車` 後綴、括號備註
- 客戶資訊分頁：狀態（有效會員）、加入時間、最近對話時間、已連接社群、記事本
- 有顧客標籤（可篩選），但標籤清單無法一次列出（標籤量統計頁要打名稱查）
- 沒有看到：電話欄位、車款欄位、分級欄位（S/A/B/C 只在瑋瑋口述與他的表）

# Conversation Structure
- URL：`/message-center/{orgId}/conversation/{conversationId}/customer/{lineUserId}`（lineUserId 是 `U` 開頭 32 hex）
- 訊息有：發送者（客戶名／客服人員＋員工名縮寫／聊天機器人）、時間、文字、圖片、貼圖
- 列表預覽可見「聊天機器人:👇點選下方看更多資訊！」→ 有機器人在跑（聊天機器人收件匣 3 則）

# Staff Structure
11 位客服（成員績效表）。指派後由個人獨占。**已指派案件平均處理 32 小時、完成率 9%；
未指派反而 1 小時 56 分、32%。** 累積未完成合計約 1,776 件。

# LINE Structure
- 三個官方帳號（瑋瑋口述）；這個組織連的 OA 顯示名稱是「瑋瑋中古車」
- **群組對話**（9/4 實查）：是「瑋瑋中古車＋客戶＋業務」的三方 LINE 群，例如
  「瑋瑋中古車, 小飛, 志豪，迪」「洛知予, 洛知予, 瑋瑋中古車」「瑋瑋中古車, Xuan, 林俊男」；
  多數狀態是「您已退出群組」「有成員退出群組」，日期 7 月～8 月。
  → **看起來是每位客戶開一個群的銷售習慣**，不是內部員工協調群。
- **9/4 捲到底確認**：群組約 15 個，最早 2025-07-20，幾乎全部「您已退出群組」或「有成員退出群組」；
  有以車命名的群（「2023 mazda3」）＝一筆交易一個群；**「瑋瑋中古車核心群」（2025-11-03）也是已退出**
  → 內部核心群曾經把官方帳號拉進去，之後退出了。
  → **結論：內部員工脈絡拿不到**（員工用自己的 LINE 群，官方帳號不在裡面）。規格裡「員工群＋客戶對話」的合併
  在 v0.1 做不到；要的話得請瑋瑋把官方帳號重新加回核心群（那是他的決定，也有隱私面）。
