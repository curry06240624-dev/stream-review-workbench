# 瑋瑋中古車｜訊息組 SABC 客戶分級規則（公司原文，Curry 2026-09-07 貼來）

SABC 看「成交階段」；結果標籤看「目前結果／狀況」。兩套分開記。

## 公司原文（摘要保留原意）

- **C｜尚未進入有效對談**：沒有真人回覆、只有點擊線上車庫、只有互動還沒聊需求。不投入大量時間，等客戶再觸發。「有點、有看」不等於有效客戶。
- **B｜已有真人互動，但資料還不完整**：願意真人回覆、有需求或興趣，但 車款方向／預算／可接受月繳／購買時間／用車需求／其他條件 尚未完整。任務是把資料問完整，不是急著成交。
- **A｜核心資料已掌握，可以持續推進**：已有明確車款或方向、預算或月繳、基本條件、預算與車款基本匹配。下一步：拆卡點、補資料、推車、通話、確認貸款條件與決策者。客戶說「我再看看」不代表降回 B，那多半是卡點。
- **S｜已進入高推進動作**：明確約看車、已來店、視訊看車、已收訂／匯訂、已拉群、準備送貸、已拉群送貸、鎖車或其他實際成交流程。當日優先處理：追訂金、追送貸、補資料、鎖車、安排下一個成交節點。
- **B 長週期**：有真實需求但 30 天後以上才買、有延後原因、有車款、有預算、有完整紀錄。建表保留、設回追日、定期追蹤，到日主動聯絡。長週期不是爛客戶。
- **結果標籤**（跟 SABC 分開）：可做／待驗證／已送貸／未過件／補保人／多查／長週期／純研究。拉群送貸＝S，後來沒過件仍是 S，另標「未過件」；來店＝S，沒付訂是結果沒完成，不代表來店不存在。
- **口訣**：C「有沒有真的聊起來？」沒有→C。B「聊起來之後核心資料齊不齊？」不齊→B。A「車款、預算／月繳、條件是不是已掌握？」是→A。S「有沒有約看、來店、視訊、收訂、拉群送貸？」有→S。

## 系統怎麼推算（`src/engine/grade.ts`，寫進 `leads.grade_auto`，畫面標「系統推算」）

| 級 | 系統判斷（訊息＋漏斗事件） |
|---|---|
| S | 有 預約成立／到店 事件，或這位客戶有成交紀錄，或對話裡（客戶或員工）出現 視訊／訂金／收訂／匯訂／付訂／下訂／拉群／送貸／進件／送件／對保／鎖車／保留車／過件／撥款 |
| A | 有真人對談（客戶自己打過字＋員工回過）＋ 車款已知（車卡／車款字眼／lead 綁車）＋ 錢已知（客戶自己講過 預算／X 萬／月繳 X／頭期／X 萬以內） |
| B | 有真人對談，但車款或錢缺一 |
| C | 沒有真人對談（只有按選單、只有機器人、或客戶打了字但沒人回） |

- **長週期**（A／B 另加標籤）：客戶說 幾個月後／年底／過年後／明年／下半年／之後再說／還沒那麼快。
- **結果標籤**：未過件（倒件／沒過件／退件／被拒）、已送貸（送貸／進件／送件／對保／已送）、純研究（只是看看／先看看／研究／參考／觀望，且錢還沒講）。
- 訊息組在 Super 8 標的分級（B@ 這種）另外放在 `contacts.grade`，畫面上跟系統推算並排，不互相覆蓋。
- 分級是「現在推進到哪」：每次分析重算；結案（成交／流失）的客戶保留最後一次的級。

## 已知限制

- 「購買時間」「用車需求」「決策者」目前不判，A 只看車款＋錢。
- 送貸／過件多半在成交群或貸款群發生，客戶對話裡看不到 → S 會偏少，等群組匯出進來再補。
- 訊息組實際標的級（Super 8 標籤）只有 40 段有，其餘要 Super 8 客戶清單匯出才有。
